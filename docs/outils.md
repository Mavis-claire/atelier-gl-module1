# Presentation des Outils utilises
## 1. Python 
Python est un langage de programmation interprété, polyvalent et facile à apprendre. Il est utilisé dans plusieurs domaines, notamment le développement logiciel, l'intelligence artificielle et l'analyse de données.
Dans ce projet, Python est utilisé pour développer le programme principal.


## 2. Visual Studio Code (VS Code)

Visual Studio Code est un éditeur de code développé par Microsoft. Il permet d'écrire, de modifier et de déboguer des programmes dans plusieurs langages de programmation grâce à ses extensions.
Dans ce projet, il est utilisé comme environnement de développement.

## 3. Git

Git est un système de gestion de versions décentralisé. Il permet de suivre les modifications apportées aux fichiers, de conserver l'historique d'un projet et de travailler avec des branches.
Dans ce projet, il sera utilisé pour gérer les différentes versions du code source.

## 4. GitHub

GitHub est une plateforme d'hébergement de dépôts Git. Elle facilite le partage de projets, la collaboration entre développeurs et le suivi des problèmes à travers les issues.
Dans ce projet, il sera utilisé pour héberger notre dépôt distant et partager notre travail.
