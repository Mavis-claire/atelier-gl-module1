# Atelier GL - Module 1

## 1. Objectif du projet

Ce projet a pour objectif de mettre en pratique les notions fondamentales du génie logiciel à travers l'installation et la configuration des outils de développement, la création d'un projet Python, la gestion des versions avec Git et la publication du dépôt sur GitHub.

## 2. Prérequis

Pour utiliser ce projet, les outils suivants sont nécessaires :

- Python 3 installé.
- Visual Studio Code.
- Git installé et configuré.

## 3. Structure du projet

```text
atelier-gl-module1/
│
├── src/
│   └── main.py
│
├── docs/
│   └── outils.md
│
├── tests/
│
├── README.md
│
└── .gitignore
```

## 4. Exécution du programme

Pour exécuter le programme, ouvrez un terminal à la racine du projet et saisissez la commande suivante :

```bash
python src/main.py
```

Le programme affiche un message de bienvenue dans le terminal.
## 5. Outils utilisés

Les outils utilisés pour réaliser ce projet sont :

- **Python :** langage de programmation utilisé pour développer le programme.
- **Visual Studio Code :** éditeur de code utilisé pour écrire et modifier les fichiers.
- **Git :** système de gestion de versions utilisé pour suivre les modifications du projet.
- **GitHub :** plateforme utilisée pour héberger le dépôt distant et faciliter le partage du projet.
